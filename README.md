# ArcticClone2025
Repository for R code and raw data associated with the manuscript "Erysipelothrix rhusiopathiae clone reemergence in association with a multi-year mass mortality event in High Arctic muskoxen (Ovibos moschatus)"

# Prerequisites
R and RStudio are necessary for running the R code. The following R packages are required: "AER","aod","beepr","car","corrplot","dplyr","extrafont","flextable","foreign","ggplot2","ggsci","ggthemes","GlmSimulator","glmulti","Hmisc","kableExtra","knitr","MASS","MuMIn","pROC","readr","readxl","reshape2","ResourceSelection","stats","survival","table1","tidyverse","vtable"
